## Project Overview
Designed and deployed a virtualized security architecture using GNS3, pfSense, and Suricata to analyze and mitigate malicious network traffic.

### Key Features
* **Custom Suricata Rules:** Written to detect TCP SYN floods and port scanning attempts.
* **Isolated Subnets:** Configured DMZ, internal LAN, and management interfaces.
* **Logging Pipeline:** Integrated with syslog for real-time alert visibility.
